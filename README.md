The **Smart Electric Vehicle Grid Integration System with V2G Optimization** is an advanced platform that integrates a large-scale EV charging network with the IEEE 33-Bus distribution system. It uses GPU acceleration to efficiently manage **25,000 EVs** in real time while optimizing grid stability and financial performance through intelligent Vehicle-to-Grid (V2G) operations.The **Power System Integration** module (**PSO.py**) implements the IEEE 33-Bus **Forward-Backward Sweep** load flow algorithm using a **100 MVA** base power and **12.66 kV** base voltage. It performs power flow calculations, voltage analysis, and grid stability assessment across all 33 buses.The **V2G Environment** (**code.py**) applies **Reinforcement Learning (RL)** to optimize EV charging and discharging decisions. It incorporates dynamic electricity tariffs, real-time **State of Charge (SOC)** monitoring, grid demand factors, and flexible scheduling. The charging power ranges from **3–22 kW**, with energy transfer between **1.5–11 kWh** per 30-minute slot while satisfying battery and SOC constraints.The **Performance Visualization** module (**new.py**) provides four analytical dashboards: **EV Load Analysis**, **Dynamic Tariff Structure**, **Action Distribution**, and **Financial Performance**. It visualizes charging/discharging behavior, net EV load, peak demand, tariff variations (**₹5–11/kWh**), charging states (**CHARGE, DISCHARGE, HOLD**), and real-time profit, cost, revenue, and cumulative financial metrics.The system includes **GPU acceleration** for large-scale processing, **48 half-hour scheduling slots**, demand-response optimization, and dynamic pricing for efficient energy management. Financial optimization algorithms maximize profit while minimizing charging costs through intelligent tariff-based decision-making.The project supports **grid management** through load balancing, peak shaving, and voltage regulation, while improving **financial planning** with revenue optimization, cost reduction, and ROI enhancement. It also promotes **environmental sustainability** by increasing grid efficiency, enabling renewable energy integration, and reducing carbon emissions.Overall, this project combines **power systems engineering, reinforcement learning, GPU computing, and financial optimization** to create a scalable, intelligent, and sustainable V2G ecosystem capable of efficiently managing large-scale EV charging while ensuring grid reliability and economic benefits.
